# Simulador-de-Frete
Neste Código HTML com CSS e JavaScript, eu fiz uma Página Web de Calculo de Frete de Cliente
Quando o Cliente é Premium Qualquer compra dele o frete será Grátis
Quando o Cliente é Comum, Ele pode Ganhar Frete Grátis, Mas ele tem que atender aos Certos Requisitos:
1° A Compra Maior de R$150,00
2° A Distância Tem que ser Menor que 90Km
